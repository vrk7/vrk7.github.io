A full-stack RAG application for legal documents.

- **Retrieval.** Document parsing, chunking and embedding-based semantic retrieval over pgvector / ChromaDB.
- **Interface.** A React frontend with a streaming SSE UI.
- **Architecture.** A clean API layer with a pluggable retrieval backend.
- **Quality.** A comprehensive automated test suite gating merges in CI (pytest, GitHub Actions) for regression-safe releases.
