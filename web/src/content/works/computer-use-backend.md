A session-centric Backend-for-Frontend wrapping a long-running agent loop.

- **Concurrency.** Per-session locking to prevent concurrent-mutation races.
- **State.** Durable server-side state with replayable history.
- **Streaming.** SSE streaming to the client for reliable multi-turn synchronisation.
